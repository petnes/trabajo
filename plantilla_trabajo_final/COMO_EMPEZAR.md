# Cómo ponerlo en marcha (10 minutos)

1. En github.com: New repository → nombre del trabajo → **Private** → Create.
2. "uploading an existing file": arrastra el contenido de esta carpeta (CLAUDE.md y las carpetas). Mete todo el material del cliente en `material/`.
3. Entra en claude.ai/code → conecta GitHub → elige el repositorio → inicia una sesión en la nube.
4. Primer mensaje:

   > Lee CLAUDE.md y haz las fases 1 y 2. Para cuando tengas el índice.

5. Revisa `trabajo/02_indice.md`. Si te convence:

   > Índice aprobado. Redacta todos los apartados (fase 3), luego monta el Word final (fase 4) y haz la revisión (fase 5).

6. Descarga el Word desde `trabajo/final/` en GitHub (botón Download).

El saldo de los 250 US$ se ve en claude.ai → Configuración → Uso. Caduca el 4 de noviembre.
